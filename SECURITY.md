# Sicherheitslücken melden / Reporting a vulnerability

PermLens hat Zugriff auf Proxmox-Hosts. Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern vertraulich über GitHub: Reiter **Security → Report a vulnerability** in diesem Repository.

Hilfreich sind: betroffene Version (steht unten auf jeder Seite), Version des Wächter-Scripts (Einstellungen), was passiert und wie es sich nachstellen lässt. Ich antworte so bald wie möglich, meist innerhalb einer Woche. PermLens ist ein Hobbyprojekt, eine feste Reaktionszeit gibt es nicht.

**Unterstützt** wird nur die jeweils neueste Version. Was PermLens auf dem Host darf und wo die bekannten Grenzen liegen, steht in [docs/SICHERHEIT.md](docs/SICHERHEIT.md).

---

PermLens has access to Proxmox hosts. Please do **not** report vulnerabilities as a public issue, but privately via GitHub: **Security → Report a vulnerability** in this repository.

Useful details: affected version (shown at the bottom of every page), guard script version (Settings), what happens and how to reproduce it. I will answer as soon as I can, usually within a week. PermLens is a hobby project, so there is no fixed response time.

Only the **latest version** is supported. What PermLens may do on the host and its known limits are described in [docs/SICHERHEIT.en.md](docs/SICHERHEIT.en.md).
